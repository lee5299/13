# 외부 구성요소

- .NET / WPF: Microsoft, [dotnet/wpf](https://github.com/dotnet/wpf), MIT. SDK/런타임은 별도 설치하거나 자체 포함 배포로 구성한다.
- Microsoft.Data.Sqlite.Core 10.0.14: [공식 소스](https://github.com/dotnet/efcore), MIT.
- SQLitePCLRaw.bundle_e_sqlite3 3.0.5: [공식 소스](https://github.com/ericsink/SQLitePCL.raw), Apache-2.0 및 포함한 SQLite 구성요소의 고지. NuGet 복원 시 실제 패키지의 LICENSE/NOTICE를 확인한다.
- restic 0.19.1: [공식 소스/배포](https://github.com/restic/restic/releases/tag/v0.19.1), BSD-2-Clause. `도구/restic-LICENSE.txt`를 함께 보존한다. 실행파일은 저장소에서 제외하고 공식 배포본의 고정 SHA256을 확인해 준비한다.

Windows Shell 연결의 변경 배치를 이해하기 위해 [Lively의 원본 설명](https://github.com/rocksdanister/lively/blob/core-separation/src/Lively/Lively/Core/WinDesktopCore.cs)을 참고했다. 해당 프로젝트의 GPL 구현을 이 앱의 종속성으로 포함하거나 전체 구현을 복사한 것은 아니다. 이 앱의 창에 SetParent/창 스타일을 적용한 자체 연결 경로이며 별도의 실제 동작 검증이 남아 있다.

이 파일은 프로젝트 자체의 소프트웨어 라이선스를 새로 선택하지 않는다.
